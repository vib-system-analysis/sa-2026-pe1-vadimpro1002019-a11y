# Глоссарий команды

Черновые определения для согласования всей командой. Пополнять и менять их следует совместно, чтобы термины одинаково понимались в документах, коде и оценках.

| Термин | Определение |
| --- | --- |
| Разговор | Один контакт оператора с клиентом в рамках одной записи или связанной сессии. |
| Запись | Аудиофайл разговора до преобразования в текст. |
| Расшифровка | Текстовая версия речи с указанием говорящих и, если доступно, временных отметок. |
| Оператор | Сотрудник, который общается с клиентом и чья работа оценивается по рубрике. |
| Супервизор | Человек, который проверяет качество работы операторов и разбирает спорные оценки. |
| Чек-лист | Перечень вопросов и требований, по которым проверяется разговор. |
| Рубрика | Чек-лист с описанием уровней оценки и правилами их применения. |
| Критерий | Один конкретный пункт рубрики, которому можно присвоить результат оценки. |
| Доказательная цитата | Короткий фрагмент расшифровки, показывающий, почему выставлен результат по критерию. |
| Оценка | Результат проверки разговора по одному или нескольким критериям рубрики. |
| Критичное нарушение | Событие, для которого недостаточно обычного снижения балла и нужен отдельный разбор или эскалация. |
| Эскалация | Передача критичного или спорного случая ответственному человеку по установленному порядку. |
| Оспаривание | Запрос оператора на повторную проверку оценки с указанием спорного критерия. |
| Повторный разбор | Проверка спорного разговора человеком с учётом записи, расшифровки и правил рубрики. |
| Сегмент | Узкая группа пользователей с общим рабочим процессом и сходной проблемой. |
| North Star | Главная метрика, показывающая, получает ли пользователь ценность от продукта. |
| Задержка | Время от получения входных данных до готового результата оценки. |
| Цена запроса | Полная переменная стоимость обработки одного разговора, включая распознавание речи и оценку. |
| Персональные данные | Сведения, позволяющие прямо или косвенно определить человека. |
| Обезличивание | Удаление или преобразование сведений так, чтобы нельзя было определить человека без дополнительных данных. |
| Синтетический разговор | Искусственно созданный или разыгранный диалог, не содержащий реальных данных клиента. |
| Эталонный пример | Проверенный человеком пример входных данных и ожидаемого результата для оценки качества системы. |
| Внедрённая в разговор инструкция | Реплика, которая пытается заставить систему изменить правила оценки вместо анализа разговора. |
